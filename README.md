# Zerodha Clone

A full-stack Zerodha Clone built using React.js, Node.js, Express.js, and MongoDB. This project replicates the core features and user interface of Zerodha with a responsive frontend and backend API integration.

## Features

- Responsive UI
- User Authentication
- Dashboard
- Holdings & Positions
- Buy/Sell Functionality
- REST APIs
- MongoDB Integration

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- HTML
- CSS
- JavaScript

## Installation

### Clone the repository

```bash
git clone https://github.com/Vibhuti-prog/Zerodha.git
```

### Install dependencies

#### Frontend

```bash
cd frontend
npm install
npm start
```

#### Backend

```bash
cd backend
npm install
npm start
```
